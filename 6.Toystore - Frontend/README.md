
# Toystore - frontend

Фронтенд для учебного проекта Toystore. Цель — разобраться, как устроен фронтенд и как он взаимодействует с REST API. Специально выбран чистый JavaScript без фреймворков: чтобы понять сам протокол, механику запросов, роутинг и работу с состоянием, а не изучать абстракции React.

Бэкенд проекта — [Toystore - node.js training](../4.%20Toystore%20-%20Docker%20+%20Redis/), развёрнут в Docker на Raspberry Pi 4.

## Стек

- **JavaScript (ES-модули)** — без фреймворков и без TypeScript
- **Vite** — dev-сервер с hot reload и проксированием запросов к API
- **Fetch API** — встроенный в браузер HTTP-клиент
- **Hash-роутинг** — собственный, без библиотек
- **CSS** — минимальный, только функциональность

## Что уже реализовано

- **Клиент для API** (`api/client.js`): единая точка для запросов, автоматическое добавление заголовков (`Content-Type`, `Authorization`, `x-session-id`), единый формат ошибок, заложена логика refresh-токена.
- **Hash-роутер** (`utils/router.js`): связывает URL с функцией рендера, поддерживает параметры (`/products/:id`).
- **Страница проверки связи** (`/health`, `/dbcheck`).
- **Каталог товаров** (`/products`): список, поиск, пагинация.
- **Карточка товара** (`/products/:id`): полное описание, характеристики.
- **Навбар** — вынесен в компонент, готов к добавлению логики авторизации.

## Планы

- Авторизация: логин, регистрация, логаут, профиль.
- Защита страниц (редирект на логин для неавторизованных).
- Корзина: просмотр, добавление, изменение, удаление.
- Заказы: оформление из корзины, список, детали.
- Админка: CRUD товаров, смена статусов заказов, аналитика.

## О разработке на Raspberry Pi

Основная среда разработки — Raspberry Pi 4, доступ по SSH из VS Code Remote. Фронтенд и бэкенд запускаются на Pi, браузер — на десктопе. Такая схема позволяет обойти ограничения десктопа (нет Docker, нет виртуализации) и одновременно получить опыт работы в удалённой среде.
