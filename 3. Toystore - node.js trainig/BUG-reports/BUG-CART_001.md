
# BUG-CART-001: Отсутствие проверки остатков на складе при повторном добавлении товара в корзину

## 📋 Основная информация

| Поле | Значение |
|------|----------|
| **ID** | BUG-CART-001 |
| **Проект** | ToyStore API |
| **Компонент** | Cart / Модель `CartModel.addItem` |
| **Тип** | Функциональный баг |
| **Приоритет** | 🔴 High |
| **Severity** | 🔴 Critical |
| **Статус** | ✅ Fixed |
| **Дата обнаружения** | 2026-10-15 |
| **Дата исправления** | 2026-10-15 |


---

## Описание

При повторном добавлении одного и того же товара в корзину (UPSERT через `ON DUPLICATE KEY UPDATE`) проверка остатков на складе работает некорректно. Валидация проверяет только **новое добавляемое количество**, но не учитывает количество, которое уже находится в корзине.

В результате пользователь может добавить в корзину товара больше, чем есть на складе.

---

## Шаги воспроизведения

**Предусловие:** товар с `id = 1` имеет остаток на складе `quantity = 10`.

1. Открыть корзину (авторизованный пользователь или гость)
2. Добавить товар `product_id = 1` в количестве `8`  
   → `POST /api/cart/items` с телом `{ "productId": 1, "quantity": 8 }`
3. Убедиться, что товар добавлен (в корзине 8 единиц)
4. Повторно добавить тот же товар в количестве `5`  
   → `POST /api/cart/items` с телом `{ "productId": 1, "quantity": 5 }`

---

## Фактический результат

Запрос **успешно выполняется**. В корзине оказывается **13 единиц** товара, хотя на складе только **10**.

Ответ API:
```json
{
    "success": true,
    "message": "Товар добавлен в корзину",
    "data": {
        "product_id": 1,
        "quantity": 5
    }
}
```

**Проблемы:**
- Нарушена бизнес-логика интернет-магазина
- Пользователь может оформить заказ, который невозможно выполнить
- При оформлении заказа упадёт проверка остатков (или того хуже — уйдёт в минус)

---

## Ожидаемый результат

Запрос должен вернуть **ошибку 400 Bad Request**:

```json
{
    "success": false,
    "message": "Недостаточно товара \"iPhone 15 Pro Max\" на складе. Доступно: 10, запрошено: 13"
}
```

---

## 🔍 Причина

В методе `CartModel.addItem` валидация проверяла только **новое количество** из запроса, а не **суммарное**:

```javascript
static async addItem(userId, sessionId, productId, quantity) {
    await this.checkStock(productId, quantity);  // проверка только нового количества
    // ...
}
```
##  Исправление

Добавлено получение текущего количества товара в корзине и проверка **суммарного** количества
