#  ToyStore API

**RESTful API**  
Учебный проект, демонстрирующий навыки разработки бэкенда на **Node.js** с использованием **Express** и **MySQL**.
В ходе работы я освоил полный цикл создания серверной части приложения — от проектирования базы данных до развертывания готового API и тестирования.

## 📋 О проекте

Этот проект — результат моего погружения в **бэкенд-разработку**.  
Я создал бэкенд для интернет-магазина игрушек, который поддерживает:

-  **Аутентификацию и авторизацию** (JWT, refresh токены, bcrypt)
-  **Корзину** (для авторизованных пользователей и гостей)
-  **Заказы** (с транзакциями и проверкой остатков)
-  **Отзывы** на товары
-  **Админ-панель** (управление товарами, заказами, аналитика)
-  **59 запросов в Postman** с полным покрытием (138 тестов)

В процессе работы я освоил все ключевые навыки, необходимые junior-разработчику:
- проектирование REST API
- работа с реляционными базами данных
- безопасное хранение паролей и токенов
- написание читаемого и структурированного кода
- тестирование API через Postman
- документирование проекта

##  Ключевые навыки, освоенные в проекте

###  Базы данных и SQL
- Проектирование схемы данных для интернет-магазина
- Сложные JOIN-запросы с несколькими таблицами
- Древовидные структуры (категории)
- Транзакции для атомарных операций (создание заказа)
- Индексы для оптимизации запросов
- Агрегатные функции для аналитики

### Безопасность и аутентификация
- Хеширование паролей с bcrypt (10 раундов)
- JWT аутентификация: Access (15 мин) и Refresh (7 дней)
- Одноразовые refresh токены, хранящиеся в БД
- Отзыв токенов при выходе
- Автоматическая очистка просроченных токенов через cron
- Защита от SQL-инъекций (плейсхолдеры, белые списки)
- Разграничение прав (user / admin)
- Защита админ-маршрутов через middleware

### REST API
- Полный CRUD для всех сущностей
- Фильтрация, сортировка, пагинация
- Вложенные ресурсы (отзывы к товарам)
- Единый формат ответов API
- Централизованная обработка ошибок
- Валидация данных на уровне контроллеров

### Архитектура и код
- Четкое разделение ответственности (MVC)
  - **Модели** — работа с БД и бизнес-логика
  - **Контроллеры** — обработка запросов и ответов
  - **Маршруты** — связь URL с контроллерами
  - **Middleware** — аутентификация и авторизация
  - **Сервисы** — утилиты и планировщик
- Асинхронное программирование с async/await
- Работа с переменными окружения

###  Тестирование
- Postman коллекция: 59 запросов
- 138 тестов, покрывающих позитивные и негативные сценарии
- Автоматическое сохранение и обновление переменных
- Тестирование всех эндпоинтов: от аутентификации до аналитики
- Проверка HTTP статусов, структуры ответов, ошибок

##  Функциональность проекта

### Реализовано полностью 

#### Товары
- Получение списка с фильтрацией по категории, цене, бренду
- Поиск по названию и описанию
- Пагинация и сортировка
- Получение товара по ID

#### Категории
- Древовидная структура
- Получение категории с подкатегориями

#### Аутентификация и пользователи
- Регистрация и вход
- JWT токены (Access + Refresh)
- Обновление токенов
- Выход из системы
- Профиль пользователя (просмотр и обновление)
- Перенос гостевой корзины при регистрации

#### Корзина
- Авторизованные и гостевые пользователи (UUID v4)
- Добавление, обновление, удаление товаров
- Проверка остатков на складе
- Очистка корзины
- Автоматическое удаление старых корзин (30 дней)

#### Заказы
- Создание заказа из корзины
- Проверка остатков (с блокировкой FOR UPDATE)
- Транзакционное создание (атомарность)
- Автоматическое списание товаров
- Автоматическая очистка корзины
- Получение списка заказов пользователя
- Получение заказа по ID

#### Отзывы
- Оставление отзыва на товар
- Обновление и удаление отзыва
- Получение отзывов товара
- Уникальность (один отзыв на товар от пользователя)

#### Админ-панель
- Создание, обновление, деактивация товаров
- Управление статусами заказов
- Статистика продаж (детальная, итоговая, последний день)
- Топ товаров

##  Postman коллекция

В папке **[Postman](./Postman)** находится готовая коллекция для тестирования API:

- **59 запросов**
- **138 тестов**
- Полное покрытие всех эндпоинтов
- Позитивные и негативные сценарии

### Переменные окружения

| Переменная | Значение | Описание |
|------------|----------|----------|
| `{{base_url}}` | `http://localhost:5000` | Базовый URL сервера |
| `{{access_token}}` | (заполняется автоматически) | JWT токен доступа |
| `{{refresh_token}}` | (заполняется автоматически) | JWT токен обновления |
| `{{user_email}}` | `test@mail.ru` | Email тестового пользователя |
| `{{user_password}}` | `123456` | Пароль тестового пользователя |
| `{{guest_session_id}}` | (генерируется) | UUID для гостевых запросов |
