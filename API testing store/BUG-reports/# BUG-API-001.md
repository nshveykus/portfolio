\# BUG-API-001: Регистрация с уже существующим email завершается успешно

\*\*ID\*\*: BUG-API-001    
\*\*Серьёзность\*\*: Major  
\*\*Приоритет\*\*: High    
\*\*Статус\*\*: Open    
\*\*Модуль\*\*: Регистрация / Аутентификация    
\*\*Техника тестирования\*\*: Негативное тестирование, граничные значения

\---

\#\#  Описание бага  
API регистрации позволяет создать нового пользователя с email-адресом, который уже зарегистрирован в системе. Ожидается, что сервер вернёт ошибку валидации, но вместо этого регистрация проходит успешно.

\---

\#\#  Шаги для воспроизведения

\*\*Предусловие\*\*: В системе существует пользователь с email \`existing@gmail.com\`

1\. Отправить POST-запрос на эндпоинт \`/api/v1/users/ \` с телом:  
json  
{  
  "name": "Ivan",  
  "email": "existing@gmail.com",  
  "password": "1234",  
  "avatar": "https://picsum.photos/8200"  
}  
2\. Проверить статус-код ответа и тело ответа. 

\---

\#\# Фактический результат

Статус-код: 201 Created

Тело ответа: Создан новый пользователь, возвращён ID пользователя

В базе данных появляется дубликат записи с тем же email

—

\#\# Ожидаемый результат

Статус-код: 400 Bad request

json  
{  
    "error": "User with this email already exists",  
    "code": "EMAIL\_ALREADY\_REGISTERED"  
}
