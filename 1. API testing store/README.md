# API Тестирование интернет-магазина


Коллекция тестов для REST API интернет-магазина.
Проект демонстрирует навыки функционального тестирования API, включая проверку CRUD операций, авторизацию, обработку ошибок и валидацию данных.

---

## 

- **Postman** — создание и выполнение запросов
- **JavaScript** — написание тестовых скриптов
- **JSON** — формат данных
- **Bearer Token** — авторизация
- **Переменные окружения** — динамическая передача данных между запросами

---

### Товары (Products)
- GET /products — получение списка товаров
- GET /products/{id} — получение товара по ID (существующему и несуществующему)
- GET /products?title={query} — поиск по названию
- GET /categories — получение списка категорий

### Пользователи (Users)
- POST /users — создание нового пользователя
- POST /users/is-available — проверка доступности email
- PUT /users/{id} — обновление данных пользователя (с токеном и без)

### Авторизация (Auth)
- POST /auth/login — вход с корректными/некорректными данными

---

### Настройка окружения
- base_url = https://api.escuelajs.co  Базовый URL API
- id = 0  Будет заполнено автоматически после создания пользователя
- access_token =  Заполнится при успешной авторизации
- refresh_token =  Заполнится при успешной авторизации

### Автоматизация
В запросах Создание нового пользователя и Успешная авторизация используются скрипты для автоматического сохранения данных в переменные окружения
