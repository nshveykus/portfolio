  ## BUG-API-002: Смена email без access-токена

# BUG-API-002: Изменение email пользователя без авторизации (отсутствует access\_token)

**ID**: BUG-API-002    
**Серьёзность**: Major   
**Приоритет**: High    
**Статус**: Open    
**Модуль**: Профиль пользователя / Безопасность    
**Техника тестирования**: Тестирование авторизации, негативное тестирование

---

##  Описание бага  
Эндпоинт смены email пользователя не проверяет наличие валидного access-токена в заголовке Authorization. Запрос успешно обрабатывается даже при полном отсутствии токена, что позволяет изменить email любого пользователя.

---

##  Шаги для воспроизведения

1. Отправить PUT-запрос на эндпоинт /api/v1/users/{{id}}  с телом:  
json  
{  
    "email": "Ivan@gmail.com"  
}  
2. Не передавать заголовок Authorization: Bearer <token>  
3. Проверить статус-код ответа  
4. Опционально. Передать невалидный токен \- результат должен быть аналогичным

---

## Фактический результат

- Статус-код 200 ok  
- Тело ответа: Email успешно изменён (возвращены обновлённые данные пользователя)  
- В базе данных email обновлён без проверки прав доступа

---

## Ожидаемый результат

- Статус-код: 401 Unauthorized либо 403 Forbidden

- Тело ответа:

json

{  
    "error": "Authentication required",  
    "code": "MISSING\_ACCESS\_TOKEN"  
}
